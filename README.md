# zt-yaml-essentials-for-ansible

This lab teaches you the basics of YAML, a simple yet powerful data serialization language. It includes practical examples of how YAML is used within Ansible. No prior knowledge of YAML or Ansible is required. By the end of this lab, you will have a foundation in YAML and an understanding of how it applies to Ansible.
