# Module 1: Your First Playbook

## Learning Objective
Run the simplest possible Ansible playbook and understand basic YAML structure.

## Key Concepts
- What YAML is and why Ansible uses it
- YAML document markers (`---`)
- Key-value pairs (`name: value`)  
- Colon-space syntax requirement
- Indentation significance

## Hands-on Activity
- Open `webserver.yml` in VSCode
- Read the minimal play (name and hosts)
- Run `ansible-playbook webserver.yml`
- Observe "no tasks to run" output

## Success Criteria
- Learner runs playbook successfully
- Understands this is valid YAML but does nothing yet
- Ready to add functionality
