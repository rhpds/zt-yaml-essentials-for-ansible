# Module 01: Why YAML? Introduction and advantages

### Brief Overview

This module introduces learners to YAML and explains why it is the foundation of Red Hat Ansible Automation Platform. Participants will understand what Red Hat Ansible Automation Platform is, why YAML was chosen as the content language for Playbooks and configurations, and the advantages YAML offers over other data formats. This sets the context for the hands-on work in subsequent modules, giving learners a clear understanding of why mastering YAML syntax is essential for working with Red Hat Ansible Automation Platform.

### Audience and Time

- **Target personas:** Developers, system administrators, DevOps engineers, or anyone new to Ansible Automation Platform
- **Experience level:** Beginner
- **Prerequisites for this module:** None
- **Estimated duration:** 8 minutes

### Learning Objectives

- Explain what Red Hat Ansible Automation Platform is and why it uses YAML
- Identify the key advantages of YAML over other data serialization formats (JSON, XML)
- Recognize the role of YAML in Red Hat Ansible Automation Platform Playbooks and configurations

### Detailed Steps

1. Open the lab introduction page in the browser view
2. Read the "What is Red Hat Ansible Automation Platform?" section:
   - End-to-end automation platform for configuring systems, deploying software, and orchestrating workflows
   - Includes tools and resources to create, manage, and scale automation across the enterprise
   - Used by thousands of organizations worldwide for IT automation
3. Read the "What is YAML?" section explaining that YAML stands for "YAML Ain't Markup Language" and is a human-readable data serialization language
4. Review examples showing YAML compared to JSON or XML to illustrate readability differences
5. Read the "Why Red Hat Ansible Automation Platform uses YAML" section:
   - YAML offers a straightforward, human-readable way to write Ansible configurations, tasks, and Playbooks
   - Playbooks must be both human-readable (for collaboration) and machine-parseable (for automation)
   - YAML's clean syntax reduces errors and makes automation accessible to broader teams
6. Observe sample Ansible Playbook snippets showing clean, readable YAML structure
7. Read the "YAML advantages" section highlighting:
   - Simplicity: minimal syntax compared to JSON or XML
   - Readability: looks like structured English prose
   - Ease of learning: beginners can read and write YAML quickly
   - Version control friendly: line-based structure works well with git
8. Understand that mastering YAML is the first step to automation success with Red Hat Ansible Automation Platform

### Key Takeaways

- Red Hat Ansible Automation Platform is an end-to-end automation platform for enterprise IT automation
- YAML is the content language for Red Hat Ansible Automation Platform - used for Playbooks, configurations, and tasks
- Red Hat Ansible Automation Platform uses YAML because it offers a straightforward, human-readable way to write automation content
- YAML's minimal syntax makes it accessible to broad teams, not just developers
- Understanding YAML is essential for anyone working with Red Hat Ansible Automation Platform
- This learning path will give you the YAML foundation needed to start automating with Red Hat Ansible Automation Platform
