# Module 01: Why YAML? Introduction and advantages

### Brief Overview

This module introduces learners to YAML and explains why it is the foundation of Ansible Automation Platform. Participants will understand what YAML is, why it was chosen for Ansible playbooks, and the advantages it offers over other data formats. This sets the context for the hands-on work in subsequent modules, giving learners a clear understanding of why mastering YAML syntax is essential for working with Ansible.

### Audience and Time

- **Target personas:** Developers, system administrators, DevOps engineers, or anyone new to Ansible Automation Platform
- **Experience level:** Beginner
- **Prerequisites for this module:** None
- **Estimated duration:** 8 minutes

### Learning Objectives

- Explain what YAML is and why it is used in Ansible Automation Platform
- Identify the key advantages of YAML over other data serialization formats
- Recognize the role of YAML in Ansible playbooks and configurations

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1       | What is YAML? | 3 min |
| 2       | Why Ansible uses YAML | 3 min |
| 3       | YAML advantages: readability and simplicity | 2 min |

### Detailed Steps

1. Open the lab introduction page in the browser view
2. Read the "What is YAML?" section explaining that YAML stands for "YAML Ain't Markup Language" and is a human-readable data serialization language
3. Review examples showing YAML compared to JSON or XML to illustrate readability differences
4. Read the "Why Ansible uses YAML" section explaining that Ansible chose YAML because playbooks must be both human-readable and machine-parseable
5. Observe sample Ansible playbook snippets showing clean, readable YAML structure
6. Read the "YAML advantages" section highlighting simplicity, minimal syntax, and ease of learning for beginners
7. Reflect on how YAML's readability supports collaboration and version control in infrastructure-as-code workflows

### Key Takeaways

- YAML is a human-readable data serialization language designed for simplicity
- Ansible uses YAML for playbooks because it balances readability and automation-friendly structure
- YAML's minimal syntax makes it easier to learn and maintain than alternatives like JSON or XML
- Understanding YAML is essential for anyone working with Ansible Automation Platform
