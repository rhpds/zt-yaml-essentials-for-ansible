# Module 3: Adding More Tasks to the List

## Learning Objective
Grow the task list and understand execution order.

## Key Concepts
- Multiple list items at same indentation
- Tasks execute top to bottom
- List order matters

## Hands-on Activity
- Add task to start httpd service
- Add task to enable httpd on boot
- Observe execution order in output
- Verify web server is running with `curl localhost`

## Success Criteria
- Learner successfully adds two more tasks
- All three tasks execute in correct order
- Understands list ordering and alignment
