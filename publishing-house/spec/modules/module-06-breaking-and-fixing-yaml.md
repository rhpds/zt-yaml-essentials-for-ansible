# Module 6: Breaking and Fixing YAML

## Learning Objective
Debug common YAML syntax errors.

## Key Concepts
- YAML is strict about syntax
- Error messages point to line and problem type
- Most errors are indentation-related
- Tabs vs spaces distinction

## Hands-on Activity
Four error exercises:
- Fix indentation error (task indented too far)
- Fix missing quotes (octal number interpretation)
- Fix missing list dash (task not recognized)
- Fix tab character (spaces vs tabs)

## Success Criteria
- Learner successfully identifies and fixes all four errors
- Understands common YAML mistakes
- Can use error messages to guide debugging
