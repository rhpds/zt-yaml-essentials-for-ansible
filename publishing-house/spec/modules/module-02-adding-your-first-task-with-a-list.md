# Module 2: Adding Your First Task with a List

## Learning Objective
Use YAML lists to add tasks to a playbook.

## Key Concepts
- Tasks are a list of actions
- YAML list syntax (dash + space)
- List items at same indentation level
- Nested structure (tasks key contains list value)

## Hands-on Activity
- Add `tasks:` key to the play
- Add ONE task as a list item
- Install httpd package
- Run and observe Ansible installing the package

## Success Criteria
- Learner successfully adds tasks section
- Playbook runs and installs httpd
- Understands dash creates list items
