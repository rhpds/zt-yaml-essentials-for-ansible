# Module 9: Build Your Own Playbook

## Learning Objective
Independent application of all YAML concepts.

## Key Concepts
- Apply all concepts from Modules 1-8
- Build complete playbook from scratch
- Debug own errors
- Prove YAML understanding

## Hands-on Activity
Build PostgreSQL database server playbook:
- Use variables for package, service, port
- Create 3-4 tasks (install, initialize, start, enable)
- Include comments explaining sections
- Use proper YAML structure

## Success Criteria
- Learner creates complete working playbook
- Demonstrates understanding of all YAML concepts
- Uses proper structure without guidance
- Can debug and fix own errors

## Bonus Challenges
- Intentionally introduce error then fix it
- Add task with multiple parameters
- Use different data types in variables
