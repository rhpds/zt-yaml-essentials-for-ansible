# Module 5: Adding Comments for Clarity

## Learning Objective
Document playbooks with comments.

## Key Concepts
- Comment syntax (`#`)
- Comments can be full-line or inline
- Comments are for humans, not Ansible
- Good comments explain "why" not "what"

## Hands-on Activity
- Add header comment explaining playbook purpose
- Add section comments grouping related tasks
- Add inline comment explaining quoting trick
- Run playbook (output unchanged)

## Success Criteria
- Learner adds meaningful comments
- Playbook still runs successfully
- Understands when and where to use comments
