# Module 8: Understanding the Complete Structure

## Learning Objective
Visualize the complete YAML hierarchy.

## Key Concepts
- Every playbook follows same structure
- Indentation creates hierarchy
- Lists of dictionaries pattern repeats
- Understanding levels (play → vars/tasks → task → module → parameters)

## Hands-on Activity
- Open `webserver-annotated.yml` with visual guides
- Trace through each indentation level
- Identify lists vs dictionaries
- Recognize the "list of dictionaries" pattern

## Success Criteria
- Learner can identify lists vs dictionaries
- Understands indentation hierarchy
- Recognizes repeating patterns
- Can predict structure of new playbooks
