# Module 4: Configuring Tasks with Dictionaries

## Learning Objective
Use nested dictionaries to add task parameters.

## Key Concepts
- Dictionaries as nested key-value pairs
- Indentation creates parent-child relationships
- Multiple levels of nesting
- When to quote values (special chars, numbers as strings)

## Hands-on Activity
- Add copy task with four parameters (dest, content, owner, mode)
- Notice parameter indentation under module name
- Understand why `mode: '0644'` needs quotes
- Verify file creation

## Success Criteria
- Learner successfully adds task
- File created with correct content/permissions
- Understands dictionary nesting through indentation
